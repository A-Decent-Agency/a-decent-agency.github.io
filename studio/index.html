Local-first, not a cloud account

No automatic upload, cloud save, collaboration server, or AI service. Your working diagram stays in this tab's memory. Download before closing or reloading. Open editable .drawio/.xml files or an Office node-map JSON. An arbitrary PDF/SVG/image is not automatically an editable set of shapes.

Double-click to edit text; drag shapes from the left; drag connector handles to join them. Use the engine's pages, layers, arrange, style, undo, and zoom tools. External images, remote fonts, cloud integrations, server PDF export, and online shape search are unavailable in this local-only edition. The top SVG/PNG buttons export the current page; download the editable map to keep every page. PNG output is automatically downscaled above eight million pixels, rather than sent to a server.
